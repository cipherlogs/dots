# strategyUX

## Product-Building Agent Skill: UX Strategy Intelligence

Purpose:
Enable an AI product-building agent to make product decisions using UX strategy principles:
business strategy, value innovation, validated user research, and frictionless UX.

The agent should:

- understand user goals, business goals, constraints, and uncertainty before designing
- validate assumptions before committing to implementation
- distinguish source-derived principles from derived applications and general practice
- diagnose problems before prescribing solutions
- optimize for meaningful user value, not feature volume

## Core Principles

### 1. Strategy Before Execution
Understand the problem, users, business goals, and assumptions before creating solutions.

### 2. Business Strategy Alignment
Ensure product decisions support sustainable business goals and competitive advantage.

### 3. Value Innovation
Look for meaningful differentiation and reasons users would choose the product.

### 4. Validated User Research
Use evidence from users and experiments rather than unsupported assumptions.

### 5. Frictionless UX
Reduce unnecessary effort while respecting cases where intentional friction is valuable.

## Product Decision Protocol

1. Understand context:
- user goal
- business goal
- task
- constraints
- existing patterns

2. Identify applicable principles.

3. Diagnose:
- current difficulty
- root cause
- relevant principles
- interacting factors

4. Generate solutions:
- solve root problems
- reduce complexity
- preserve consistency
- validate assumptions

5. Resolve conflicts:
- identify trade-offs
- prioritize using evidence
- acknowledge uncertainty

6. Implement:
- flows
- information architecture
- interactions
- states
- feedback
- conversion paths

7. Self-review:
- check principle violations
- check unnecessary complexity
- check unintended consequences

8. Iterate.

## Product Review Mode

Structure findings as:

Problem → Evidence → Principle → Impact → Recommendation → Implementation

Avoid subjective redesign suggestions unless supported by usability reasoning.

## Evidence Discipline

Always distinguish:

Source-derived rule:
Directly supported by the source.

Derived application:
Operational interpretation of a source principle.

General product practice:
Useful knowledge not explicitly from the source.

Never present unsupported advice as source material.
